# Keywords

Source: https://neo4j.com/docs/cypher-manual/current/syntax/keywords/

## 概要
- Cypherの予約語（キーワード）の一覧と識別子との関係を示す。

## ルール
- キーワードは識別子として使うことは推奨されない（変数/ラベル/型/関数/プロシージャ名）。
- 同じ綴りが識別子にもなり得る場合は**キーワードとして解釈**される。
- 例: `true` はリテラルとして解釈される。

## 回避策
- バッククォートで囲むと**識別子として解釈**される（例: `` `true` ``）。

## 備考
- キーワード一覧は将来拡張される可能性がある。
