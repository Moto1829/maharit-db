# Naming rules and recommendations

Source: https://neo4j.com/docs/cypher-manual/current/syntax/naming/

## 命名規則（概要）
- 先頭はアルファベットが推奨。数値先頭は不可。
- 記号は `_` のみ許可（パラメータは `$` から始める）。
- 大文字小文字を区別。
- 前後の空白は自動的に除去。

## 特殊文字の使用
- 数字・記号・空白などを含む場合はバッククォートで囲む。
- バッククォート内で ``\uXXXX`` 形式のUnicodeが使用可能。
- バッククォートによるユーザー入力の取り込みはCypherインジェクションに注意。

## スコープ/名前空間
- ラベル・関係タイプ・プロパティ名は同名を使ってよい。
- 同一クエリスコープ内でノード変数と関係変数は同名不可。

## 推奨命名
- ラベル: PascalCase（`:VehicleOwner`）。
- 関係タイプ: UPPER_SNAKE_CASE（`:OWNS_VEHICLE`）。

## 文字数制限
- 仕様上の識別子長制限（GQL準拠）がある。
- 例: 16,383文字の上限（ストア形式に依存）。

## 備考
- データベース名のドット（`foo.bar.baz`）は有効だが非推奨。
