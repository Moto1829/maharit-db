Graph analysis algorithms

This module provides various graph algorithms including:

  • Centrality measures (degree, closeness, betweenness)
  • PageRank
  • Community detection (connected components, strongly connected components)
  • Cycle detection and topological sort

Algorithms operating on large graphs (>= 500 nodes) use rayon for parallel computation where the algorithm structure allows it. For small graphs the sequential path is taken to avoid rayon’s thread-pool overhead.
