# タスク 170: 英語をサイトのデフォルトにするか、翻訳の鮮度チェックを失敗扱いにするかを決める

## 背景
2026-11-12、task140 で docs の全 52 ページに英語版（`.en.md`）が揃った。
task140・141 で「全ページ揃った時点で判断する」としていた次の 2 点が残っている（利用者の判断が必要）。

## 決めること
- [ ] 英語をサイトのデフォルト（ルート `/`）にするか。する場合は日本語を `/ja/` に移し、旧 URL（日本語のページ）からのリダイレクトを用意する
- [ ] `scripts/check_docs_i18n.py` を CI で失敗扱い（`--strict`）にするか。する場合、日本語だけを直すコミットは同じコミットで英語も直す必要がある
