# プロパティインデックス

## 概要
プロパティ値による高速な検索を可能にするインデックスを実装する。

## 実装内容

### 完全一致インデックス
- [ ] (プロパティ名, 値) -> ノードID集合
- [ ] HashMapベースの実装
- [ ] インデックス対象プロパティの指定

### 範囲インデックス（BTree）
- [ ] 数値プロパティの範囲検索
- [ ] BTreeMapベースの実装
- [ ] `find_by_range(prop, min, max)`

### インデックス管理
- [ ] インデックスの作成: `CREATE INDEX ON :Person(name)`
- [ ] インデックスの削除
- [ ] インデックスの一覧取得

### 自動更新
- [ ] プロパティ設定時のインデックス更新
- [ ] ノード削除時のインデックス削除
