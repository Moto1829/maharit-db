## メモリから引き継ぐ内容
タスク 195 でメモリから削った項目のうち、コードの約束事として今も有効なもの。該当するクレートの CLAUDE.md に書く（書く前に今のコードで確かめる）。

- maharit-core: ラベルの変更は必ず `add_node_label` / `remove_node_label`（ラベル索引を更新する版）を通す
- maharit-query: プロパティを変える経路（SET / REMOVE / DELETE / MERGE のプロパティ更新）では `reindex_node_property` を呼ぶ。漏れるとプロパティ索引が古くなり、索引を使う MATCH が行を取りこぼす
- maharit-query: CREATE のパターンに束縛済みの変数があれば、新しく作らずそのノードを使う
- maharit-query: `all` はキーワード（`TokenKind::All`）なので、関数 `all(...)` はパーサーで個別に扱っている。キーワードと同名の関数を足すときは同じ対応が要る
- maharit-storage: `wal_group_commit::test_group_committer_batch_100_writes` は、全体を並列で回すとタイミングで落ちることがあった（単独では通る）。今も不安定なら直すか、タスクを起こす
