# クエリオプティマイザ

## 概要
クエリの実行計画を最適化し、パフォーマンスを向上させる。

## 実装内容

### 実行計画
- [x] 論理プラン -> 物理プランの変換
- [x] プランノードの定義（Scan, Filter, Join, Sort等）
- [x] プランのツリー表現

### EXPLAIN / PROFILE
- [x] EXPLAIN: 実行計画の表示
- [x] PROFILE: 実行統計付きの実行
- [x] コスト見積もりの表示

### 最適化ルール
- [ ] フィルタのプッシュダウン
- [ ] インデックス選択
- [ ] 結合順序の最適化
- [ ] 不要なカラムの除去

### 統計情報
- [x] ノード数/エッジ数の統計
- [ ] ラベルごとの分布
- [ ] プロパティ値のヒストグラム（将来的）

### クエリキャッシュ
- [x] パースしたASTのキャッシュ
- [ ] 実行計画のキャッシュ
- [x] キャッシュの無効化

## クエリ例
```cypher
EXPLAIN MATCH (n:Person) WHERE n.age > 30 RETURN n

PROFILE MATCH (a)-[:KNOWS]->(b) RETURN a, b
```
