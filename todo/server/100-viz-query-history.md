# Task 100: maharit-viz クエリ履歴機能

## 背景・目的

Web UI でクエリを書いて実行 → 別のクエリを書く、という流れで作業すると、
さっき実行した「あのクエリ」をもう一度試したい場面が頻繁にある。
現状はブラウザリロードで入力は消えるし、過去のクエリは復元できない。

ブラウザのキャッシュ（`localStorage`）に履歴を保存し、ドロップダウンから
過去のクエリを呼び出して再実行できるようにする。

## 実装内容

### 保存仕様 (`localStorage`)

- **キー**: `maharit-viz:query-history`
- **形式**: `[{ query: string, timestamp: number }, ...]`（新しい順）
- **件数上限**: 10 件（古いものから削除）
- **重複処理**: 同じクエリを連続実行した場合は古い方を削除して先頭に移動
  （クエリ単位で重複を排除）
- **クリア API**: 「履歴クリア」ボタンを用意

### 保存タイミング

- クエリを実行して **成功** した時のみ履歴に追加
- パースエラー等のクエリは履歴に残さない（ノイズになる）

### UI 設計

- **エディタ右側の controls 行に "History ▾" ボタン**を追加
- クリックすると下方向にドロップダウンが開き、最大 10 件のクエリを表示
- 各エントリ:
  - クエリのプレビュー（先頭 60 文字くらい、改行は半角空白に）
  - 経過時間（"3 分前", "2 時間前" 等の相対表記）
  - クリックすると textarea に復元（実行はしない）
- ドロップダウンの末尾に「履歴クリア」リンク
- 外側クリックで閉じる
- ドロップダウンが空のときは「履歴がありません」を表示

### キーボード操作

- 既存の Ctrl/⌘+Enter で実行（変更なし）
- 追加: Ctrl/⌘+↑ で前のクエリ、Ctrl/⌘+↓ で次のクエリに移動（任意）

## 検証

- 何度かクエリを実行 → リロードしても履歴が保持される
- 11 件目を実行すると最も古いものが削除される
- 同じクエリの連続実行で履歴が膨らまない
- パースエラーのクエリは履歴に残らない
- ドロップダウンからクリックで復元できる
- 「履歴クリア」で localStorage が消去される

## スコープ外（将来的に考えてもよい）

- お気に入りクエリのピン留め
