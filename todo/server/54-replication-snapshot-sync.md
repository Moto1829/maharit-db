# レプリケーション: 新規フォロワーのスナップショット同期

**Status**: Completed

## 概要

新しいフォロワーが接続した際、リーダーの現在のグラフ全体をスナップショットとして
転送する初期同期を実装する。現状はハンドシェイク後に WAL のストリーミングだけが始まり、
既存データが同期されない。

## 実装内容

- [x] ハンドシェイク時にフォロワーが自身の LSN をリーダーに送る
- [x] リーダーはフォロワーの LSN が 0（新規）の場合、スナップショットを送信する
  - `maharit-storage` のシリアライズ機能を利用してグラフ全体をバイト列化
  - 新しいメッセージ `ReplicationMessage::Snapshot { data: Vec<u8> }` を追加
- [x] フォロワーはスナップショットを受け取ってローカルグラフに適用してから WAL 受信を開始する
- [x] スナップショット転送中はリーダー側の書き込みをブロック、または転送後の差分 WAL を再送する
