# クエリ言語レクサー

## 概要
Cypherライクなクエリ言語のレクサー（字句解析器）を実装する。

## 実装内容

### トークン種別
- [x] キーワード: `CREATE`, `MATCH`, `WHERE`, `RETURN`, `DELETE`, `SET`
- [x] 識別子: ノードラベル、プロパティ名、変数名
- [x] リテラル: 文字列、整数、浮動小数点、真偽値、NULL
- [x] 演算子: `=`, `<>`, `<`, `>`, `<=`, `>=`, `+`, `-`, `*`, `/`
- [x] 論理演算子: `AND`, `OR`, `NOT`
- [x] 記号: `(`, `)`, `[`, `]`, `{`, `}`, `:`, `,`, `.`, `-`, `>`
- [x] 矢印パターン: `->`, `<-`, `--`

### エラー処理
- [x] 不正な文字のエラー報告
- [x] 位置情報（行番号、列番号）の追跡

### テスト
- [x] 各トークン種別のユニットテスト
- [x] 複合クエリのトークン化テスト

## 対象クレート
`maharit-query`
