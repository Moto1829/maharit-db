# データインポート/エクスポート

## 概要
外部フォーマットとのデータ変換機能を実装する。

## 実装内容

### CSVインポート
- [x] ノードCSV: `id,label,prop1,prop2,...`
- [x] エッジCSV: `from,to,type,prop1,prop2,...`
- [x] ヘッダー解析
- [x] 型推論

### CSVエクスポート
- [x] ノードのCSV出力
- [x] エッジのCSV出力

### JSONインポート/エクスポート
- [x] ノード配列 + エッジ配列形式
- [x] 隣接リスト形式

### GraphML
- [x] GraphML形式のパース
- [x] GraphML形式の出力

### バルクローディング
- [x] 大量データの効率的な読み込み
- [x] プログレス表示

## 依存クレート候補
- `csv` - CSV処理
- `serde_json` - JSON処理

## 対象クレート
`maharit-io`
