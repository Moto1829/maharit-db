# タスク 206: リストの演算と添字・スライスを標準に合わせる

## 背景（2026-11-21、openCypher TCK）

```text
RETURN [1, 2, 3][3..1] AS r          // => [2, 3]?  期待: []（範囲が逆なら空）
RETURN [1, 2, 3][null..2] AS r       // => [1, 2]   期待: null
RETURN 'abc'[0]                      // 期待: 型エラー（リストでないものの添字）
RETURN [1, 2][1.5]                   // 期待: 型エラー（整数でない添字）
RETURN [1, 2] + 3 AS r               // => 型エラー   期待: [1, 2, 3]（リスト + 要素）
RETURN 1 IN 2                        // 期待: 型エラー（右辺がリストでない）
RETURN size(p)                       // パスに size() は型エラー（length() を使う）
```
