# シャーディング

## 概要
データを複数のノードに分散配置し、水平スケーラビリティを実現する。

## 実装内容

### シャーディング戦略
- [ ] ハッシュベースシャーディング
- [ ] レンジベースシャーディング
- [ ] ラベルベースシャーディング

### シャード管理
- [ ] シャードの追加/削除
- [ ] リバランシング
- [ ] シャードマッピングの管理

### 分散クエリ実行
- [ ] クエリルーティング
- [ ] 分散結合（Distributed Join）
- [ ] 結果のマージ

### コーディネーター
- [ ] クエリの分解
- [ ] シャードへの分散
- [ ] 結果の集約

### エッジの扱い
- [ ] ローカルエッジ（同一シャード内）
- [ ] リモートエッジ（シャード間）
- [ ] エッジのレプリケーション戦略

## 設定例
```toml
[sharding]
enabled = true
strategy = "hash"
shards = [
  { id = 1, address = "node1:7687" },
  { id = 2, address = "node2:7687" },
  { id = 3, address = "node3:7687" },
]
replication_factor = 2
```
