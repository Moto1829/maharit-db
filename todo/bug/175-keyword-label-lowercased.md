# バグ 175: キーワードと同じ名前のラベル・プロパティが小文字になる

## 現象（2026-11-15、server/173 の作業中に発見）
`CREATE (:User {name: 'u'})` で作ったノードのラベルが `user` になる。
`USER` がキーワードで、ラベルの位置では `keyword_as_ident`（`lexer.rs`）が小文字の固定文字列を返すため。
`Index` / `Role` / `Match` / `Order` など、キーワードと同じ名前は同様（ラベル、プロパティ名、`CREATE INDEX ON :User(…)`、
ACL の `ON :User(password)` も同じ経路）。

MATCH でも同じく小文字になるので、Cypher の中では一致して気づきにくい。
ただし `labels(n)` の結果やクライアント・可視化での表示、他のツールから読み込んだデータ（`User` のまま）との照合がずれる。

## 直し方の案
- 字句解析でキーワードのトークンに元の綴りを持たせ（または span から元の文字列を取り出し）、識別子として使う位置では元の綴りを返す
- 既存のデータで小文字になったラベルの扱い（移行するか、そのままにするか）を決める。結果が変わるので `fix!:` の可能性あり
