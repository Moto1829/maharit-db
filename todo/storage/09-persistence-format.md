# 永続化フォーマット

## 概要
グラフデータをディスクに保存するためのファイルフォーマットを設計・実装する。

## 実装内容

### ファイルフォーマット設計
- [x] ヘッダー構造（マジックナンバー、バージョン、メタデータ）
- [x] ノードセクション
- [x] エッジセクション
- [x] プロパティセクション
- [ ] インデックスセクション

### シリアライズ
- [x] `PropertyValue`のバイナリ表現
- [x] ノードのシリアライズ
- [x] エッジのシリアライズ
- [x] 可変長データの扱い（文字列等）

### デシリアライズ
- [x] ファイルからのグラフ復元
- [x] バージョン互換性チェック
- [x] 破損データの検出

### API
```rust
PersistentStorage::save(&graph, "data.db")?;
let graph = PersistentStorage::load("data.db")?;
```

## 対象クレート
`maharit-storage`
