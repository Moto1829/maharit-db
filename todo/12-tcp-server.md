# TCPサーバー

## 概要
ネットワーク経由でクエリを受け付けるTCPサーバーを実装する。

## 実装内容

### サーバー基盤
- [ ] TCP接続の受付
- [ ] 非同期I/O（tokio使用）
- [ ] 接続プール管理
- [ ] グレースフルシャットダウン

### プロトコル
- [ ] メッセージフレーミング（長さプレフィックス）
- [ ] リクエスト/レスポンス形式
- [ ] エラー応答

### コマンド処理
- [ ] クエリ実行リクエスト
- [ ] 結果のストリーミング
- [ ] トランザクション操作

### 設定
- [ ] バインドアドレス/ポート
- [ ] 最大接続数
- [ ] タイムアウト設定

## 依存クレート候補
- `tokio` - 非同期ランタイム
- `bytes` - バッファ操作

## 対象クレート
`maharit-server`
