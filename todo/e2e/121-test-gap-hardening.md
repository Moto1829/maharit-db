# タスク 121: テスト不足の補強（今回のバグ群から逆算）

## 背景

2026-09-30 に修正した bug/114〜120 は、いずれも既存テストが「その状況を一度も作っていない」ために見逃されていた。

| バグ | 見逃した理由（欠けていたテスト） |
|---|---|
| 114 並行書き込みで索引が消える / UNIQUE すり抜け | テストが `#[tokio::test]`（シングルスレッド）で、並行実行が一度も起きていなかった |
| 116 SET/REMOVE が複製されない | レプリケーションのテストが CREATE / DELETE しか見ていなかった |
| 117 ROLLBACK が複製されない・ラベル/エッジが戻らない | ROLLBACK のテストが単一ノードの CREATE/プロパティのみ。複製経路と組み合わせたテストなし |
| 120 フォロワーが途中で止まる | メッセージ 1 往復のテストのみ。連続送信（WAL と ACK の交差）がなく、E2E の失敗は flaky として放置 |
| 118 `SET … REMOVE` の REMOVE を黙って無視 | パーサーの「未消費トークンが残ったらエラー」を確かめる負のテストなし |
| 119 匿名ノードのパターンがエラー | 標準 Cypher の典型パターンを網羅するテストなし |
| 115 clippy 違反の混入 | `--workspace` なしで実行していた＋CI なし（task 77） |

## 補強内容

### 1. レプリケーションの差分テスト（最優先） ✅ 2026-09-30 完了
- リーダーにランダムな書き込み列（CREATE / SET / REMOVE / ラベル / DELETE / DETACH DELETE / tx+COMMIT / tx+ROLLBACK / 失敗する文）を流し、
  フォロワーのグラフがリーダーと完全一致（ID・ラベル・プロパティ・エッジ）することを検証する
- 乱数シードを固定し、失敗時はシードと操作列を出力して再現できるようにする（`rand` + 固定シード、proptest でも可）
- 今回の `rollback_is_replicated_to_followers` の snapshot 比較ヘルパーを共通化して使う

### 2. 並行実行のストレステスト
- 共有状態に触るテストは `flavor = "multi_thread"` を標準にする
- 読み書き混在（N 並列）後に「索引の内容 == グラフから再構築した索引」を検証する不変条件チェック関数を用意

### 3. パーサーの負のテスト
- 文末に未消費トークンが残る入力はパースエラーになることを、各文種について確認（bug/118 と併せて）

### 4. Cypher 適合テスト
- 典型パターン集（匿名ノード、双方向、可変長、複数パターン、OPTIONAL MATCH 等）を表形式で持ち、期待結果と比較（bug/119 と併せて）

### 5. E2E の flaky を許容しない
- E2E スクリプトは「たまに落ちる」を不具合として扱う。CI（task 77）では replication_test を複数回実行する
