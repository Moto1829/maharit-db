# タスク 161: 整数の 0 除算でサーバーが落ちる

## 現象（2026-11-12、task124 で % 演算子を追加する準備中に発見）
`RETURN 1 / 0` で `attempt to divide by zero` の panic。リリースビルドは `panic = "abort"` のため、
サーバーに送るとプロセス全体が終了する（認証を有効にしていれば reader でも、無効なら誰でも可能な DoS）。
`(-9223372036854775807 - 1) / -1` も同様。加算・減算・乗算・符号反転・abs() のオーバーフローは
リリースビルドでは黙って桁あふれした値を返していた。

## 対応
- [x] 整数の四則演算・符号反転・abs() を checked にし、`division by zero` / `integer overflow` のエラーにする
- [x] 浮動小数点の 0 除算は従来どおり Infinity
- [x] テスト、TCP サーバーで 0 除算の後も接続が使えることを確認
- 文字列・リスト・日付関数の境界値も確認し、panic は無かった
