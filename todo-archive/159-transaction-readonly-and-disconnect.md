# タスク 159: 読み取り専用トランザクションで書き込めてしまう / 切断されたトランザクションが残る

## 現象（2026-11-12、task124 で transactions.md を書き直す際に確認）
- `{"type": "begin", "readOnly": true}` で始めたトランザクションの `txId` 付きで `CREATE` すると、書き込みが通る
- `begin` してから書き込み、コミットもロールバックもせずに接続を閉じると、トランザクションは開いたままで変更も残る
  （他の接続から見える。同じ txId で後から rollback はできる）

## 期待

- 接続が切れたら、その接続で開いたまま終わっていないトランザクションをロールバックする
