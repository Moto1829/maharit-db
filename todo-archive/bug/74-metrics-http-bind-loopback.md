# bug/74: 監視 HTTP（metrics/health）の既定バインドをループバックに変更

## 概要
監視用 HTTP サーバーが `0.0.0.0:9090` に無認証でバインドしていた。
`/metrics`（Prometheus）は内部統計（ノード数・エッジ数・クエリ数・稼働時間など）を
公開するため、全インタフェースに晒すと情報漏洩になる。

## 対応
- `HttpConfig::default()` の既定バインドを `0.0.0.0:9090` → `127.0.0.1:9090`（ループバックのみ）に変更。
- `main.rs` に `--metrics-bind <ADDR>` を追加し、外部公開が必要な場合に明示的に上書き可能に。
  `spawn_http_server(Option<String>)` に変更し 3 つの起動経路へ配線。
- ヘルプテキスト更新、既定バインドのテストを更新。

## 影響
- 重大度: LOW（情報開示）
- 既定でメトリクスがローカルホストからのみアクセス可能になる（破壊的変更だが安全側）。
  Prometheus 等が別ホストの場合は `--metrics-bind 0.0.0.0:9090` を明示指定。

## ステータス
完了（server テスト 231 件パス）
