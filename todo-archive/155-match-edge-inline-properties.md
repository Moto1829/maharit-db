# タスク 155: MATCH でリレーションシップのインラインプロパティが無視される

## 現象（2026-11-09、task145 の作業中に発見）
```text
maharit> CREATE (a:A)-[:K {w: 1}]->(b:B)
maharit> MATCH (a:A) CREATE (a)-[:K {w: 2}]->(:B)
maharit> MATCH ()-[r:K {w: 1}]->() RETURN r.w
1
2
```
`{w: 1}` の条件が効かず、全ての `K` が返る。ノードのインラインプロパティは効いている。
MERGE も同じ照合を使うため、プロパティ違いのリレーションシップがあると作成されなかった。
