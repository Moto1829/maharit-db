# タスク 170: 英語をサイトのデフォルトにするか、翻訳の鮮度チェックを失敗扱いにするかを決める

## 背景
2026-11-12、task140 で docs の全 52 ページに英語版（`.en.md`）が揃った。
task140・141 で「全ページ揃った時点で判断する」としていた次の 2 点が残っている（利用者の判断が必要）。

## 決めること
- [x] 英語をサイトのデフォルト（ルート `/`）にするか。する場合は日本語を `/ja/` に移し、旧 URL（日本語のページ）からのリダイレクトを用意する
- [x] `scripts/check_docs_i18n.py` を CI で失敗扱い（`--strict`）にするか。する場合、日本語だけを直すコミットは同じコミットで英語も直す必要がある

## 決定（2026-11-21）

ユーザーから「task67 以外のタスクを全てやって」と指示があり、こちらで決めた。どちらも後から戻せる。

- 英語をサイトのデフォルトにしない。日本語が正本で、切り替えると既存の URL（日本語ページ）が変わりリダイレクトが要る。
  README は既に英語が先で、英語サイトは `/en/` にある。海外の利用者が増えてから改めて判断する
- 翻訳の鮮度チェックを失敗扱いにする（`docs.yml` と `scripts/check.sh` で `--strict`）。52 ページ全てが追従済みで、
  「日本語を直したら同じコミットで英語も直す」決まりも既にあるため、運用は変わらない
