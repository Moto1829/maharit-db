# Task 01: REPL（対話型インターフェース）

## 概要
ユーザーがコマンドラインからグラフDBと対話できるREPL（Read-Eval-Print Loop）を実装する。

## 実装内容

### 基本機能
- [x] 入力プロンプトの表示
- [x] コマンド履歴（上下キーで履歴を辿る）
- [x] 行編集（rustylineクレートの利用）
- [x] 終了コマンド（`:quit`, `:exit`, Ctrl+D）

### 組み込みコマンド
- [x] `:help` - ヘルプ表示
- [x] `:stats` - グラフの統計情報（ノード数、エッジ数）
- [x] `:clear` - 画面クリア
- [x] `:dump` - グラフ全体の表示

### 出力フォーマット
- [x] テーブル形式での結果表示
- [x] エラーメッセージのカラー表示

## 依存クレート候補
- `rustyline` - 行編集とヒストリー
- `colored` - ターミナルカラー

## 対象クレート
`maharit-server`
