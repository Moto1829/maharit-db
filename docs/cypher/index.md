# Cypher クエリ言語

MaharitDB は Neo4j 互換の Cypher クエリ言語をサポートします。

## 標準への準拠

openCypher の TCK（言語の意味を確かめるためのシナリオ集）のうち、式に関するシナリオをテストで実行しています（2026-11-21 時点）。

| 領域 | 通過 / シナリオ数 |
|---|---|
| null | 44 / 44 |
| 条件式（CASE） | 13 / 13 |
| 算術 | 6 / 6 |
| 真偽値 | 141 / 150 |
| 比較 | 61 / 72 |
| リスト | 144 / 185 |
| リテラル | 80 / 131 |
| 優先順位 | 46 / 105 |
| 文字列 | 15 / 32 |
| 時間型 | 20 / 1004 |

時間型の多くは、`localdatetime` / `time` / `localtime` や週・通日での日付の指定に対応していないため通りません。
