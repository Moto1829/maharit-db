# インデックス・制約

プロパティインデックス、全文検索インデックス、スキーマ制約の設定方法です。

## 永続化とレプリケーション

`maharit server` は、インデックス・制約・全文検索インデックスの定義をデータファイルと WAL に保存します。再起動（強制終了からの復旧を含む）すると定義が戻り、インデックスの中身は起動時にデータから作り直されます。大きなグラフでは、その分だけ起動に時間がかかります。

レプリケーションでは、定義がフォロワーにも送られます（[レプリケーション](../advanced/replication.md)）。
