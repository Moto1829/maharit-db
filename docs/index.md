# MaharitDB とは

MaharitDB は Rust で実装されたグラフデータベースエンジンです。Cypher ライクなクエリ言語を使用してノードとエッジからなるグラフデータを効率的に管理できます。組み込み用途からネットワーク越しのサーバー利用まで幅広いシナリオに対応します。

## 主な特徴

### Cypher ライクなクエリ言語

Neo4j の Cypher に近い構文でグラフデータを操作できます。`MATCH`、`CREATE`、`MERGE`、`SET`、`DELETE`、`RETURN` といった基本操作はもちろん、`UNWIND`、`WITH`、`UNION`、`FOREACH`、`CALL {}` サブクエリなど高度な構文にも対応しています。

```cypher
-- ノードを作成してリレーションを張る
CREATE (alice:Person {name: "Alice", age: 30})
CREATE (bob:Person {name: "Bob", age: 25})
MATCH (a:Person {name: "Alice"}), (b:Person {name: "Bob"})
CREATE (a)-[:KNOWS {since: 2020}]->(b)

-- グラフを検索する
MATCH (p:Person)-[:KNOWS]->(friend:Person)
WHERE p.age > 20
RETURN p.name, friend.name
ORDER BY p.name
```

### BM25 全文検索（日本語対応）

BM25 アルゴリズムに基づく高精度な全文検索インデックスを内蔵しています。lindera IPADIC による日本語形態素解析に対応しており、日本語テキストの自然な検索が可能です。フレーズ検索やファジー検索（編集距離指定）もサポートします。

```cypher
-- 全文検索インデックスを作成
CREATE FULLTEXT INDEX articleIndex FOR (a:Article) ON EACH [a.title, a.body]

-- BM25 スコアリングで検索
CALL db.index.fulltext.search("articleIndex", "グラフデータベース")
YIELD node, score
RETURN node.title, score
ORDER BY score DESC
```

### グラフアルゴリズム

グラフ理論の主要アルゴリズムを組み込みで提供します。

- **最短経路**: Dijkstra 法・BFS による重み付き/重みなし最短経路
- **全経路探索**: 深さ優先探索による指定ホップ数以内の全経路列挙
- **PageRank**: 重要度ランキング
- **中心性指標**: 媒介中心性（Betweenness）、近接中心性（Closeness）
- **連結成分**: Union-Find による連結成分・強連結成分の検出
- **コミュニティ検出**: ラベル伝播法

### WAL による永続化・耐障害性

Write-Ahead Log（WAL）によってデータの永続性を保証します。サーバーが予期せずクラッシュした場合でも、WAL を再適用することでデータを復元できます。WAL はレプリケーションのストリーミングソースとしても機能します。

### TLS/SSL 対応 TCP サーバー

rustls を使用した TLS 1.2/1.3 対応の TCP サーバーを内蔵しています。証明書のホットリロードにも対応しており、サービスを停止せずに証明書を更新できます。

### Prometheus メトリクス・OpenTelemetry トレーシング

`/metrics` エンドポイントで Prometheus 形式のメトリクスを提供します。クエリ実行時間、接続数、メモリ使用量などを監視できます。OpenTelemetry による分散トレーシングにも対応しており、クエリの実行経路を詳細に追跡できます。

### レプリケーション（リーダー/フォロワー）

WAL ストリーミングによるリーダー/フォロワー型のレプリケーションをサポートします。ハートビートによるフォロワーの生存監視と自動フェイルオーバー検出を備えています。

### バックアップ・ポイントインタイムリカバリ（PITR）

gzip 圧縮付きのフルバックアップと増分バックアップをサポートします。WAL ログを組み合わせることで、特定の時点への復元（PITR）が可能です。

## ユースケース

- **知識グラフ**: 概念間の関係を自然にモデル化し、推論クエリを実行
- **ソーシャルグラフ**: ユーザー間のフォロー・フォロワー関係の管理と分析
- **推薦エンジン**: グラフアルゴリズムを活用した協調フィルタリング
- **不正検知**: 異常なパターンをグラフ構造で検出
- **依存関係解析**: パッケージや設定の依存ツリーの管理
- **地図・経路**: 道路ネットワークの最短経路計算

## ドキュメントの構成

このドキュメントは以下の章で構成されています。

| 章 | 内容 |
|----|------|
| クイックスタート | インストールから最初のクエリまでを 10 分でひととおり体験できます |
| Cypher クエリ言語 | クエリ構文の全機能をリファレンス形式で解説します |
| 関数リファレンス | 組み込み関数・集計関数・全文検索関数を網羅します |
| インデックス・制約 | プロパティインデックス・全文検索インデックス・スキーマ制約を説明します |
| サーバー・運用 | 本番環境での設定・TLS・認証・監視・バックアップを解説します |
| 高度なトピック | トランザクション・レプリケーション・クエリ最適化を扱います |
| API リファレンス | Rust クライアントと TCP プロトコル仕様を記述します |
| グラフアルゴリズム | 組み込みアルゴリズムの使い方と性能特性を説明します |
