# アクセス制御（ACL）

!!! warning "未実装"
    ラベル単位・プロパティ単位のアクセス制御（`GRANT` / `REVOKE` / `DENY` など）は、まだサーバーで使えません。

現在のサーバーで使えるアクセス制御は、[認証・ロール管理](auth.md) の 3 つのロール（`reader` / `writer` / `admin`）だけです。ロールはクエリ全体に対して「読み取りだけ」「書き込みも可」「ユーザー管理も可」を決めます。特定のラベルのノードや特定のプロパティだけを見せない、といった制御はできません。

## 当面の代わりの方法

- 見せたくないデータは、別のデータベース（別の `--data` のサーバー）に分ける
- アプリケーション側で、ユーザーに応じてクエリを組み立てる（返す列やラベルを制限する）
- 読み取りだけでよい利用者には `reader` ロールのユーザーを使う

## 今後

`maharit-server` クレートには、ラベル・プロパティ単位の規則を評価する `AclManager`（`auth.rs`）がありますが、クエリの実行とはつながっていません。サーバーでの適用と、規則を設定する文の追加は今後の作業です（server/173）。
